# Muhammad Shahbaz — Online Resume

A responsive personal resume website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Sign in to GitHub as `Shahbaz63920`.
2. Create a **public** repository named `voltride-resume`.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. The expected URL is:
   `https://shahbaz63920.github.io/voltride-resume/`

The repository and live URL above are proposed addresses, not confirmation that publication has occurred.
